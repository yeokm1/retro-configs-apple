May 3 2019, apple-II-0.2H-F25-modelBC
- Added "Smartport Unit 2" emulation mode. FOR APPLE IIGS ONLY.
  Use "Smartport Unit 2" mode when you need Smartport Hard Disk emulation, and your Floppy Emu is daisy-chained 
  behind an Apple 3.5 inch floppy drive. Normally an Apple IIgs in this configuration could only boot from the
  Apple 3.5 inch drive (the 1st drive unit in slot 5). "Smartport Unit 2" mode causes the Floppy Emu to initially
  appear as a 5.25 inch drive in slot 6, which the IIgs will boot from and load a small bootstrap program. This
  program will modify the Smartport unit priority table in RAM to give Unit 2 priority over Unit 1, and then reboot
  from slot 5. This makes it possible to boot from the Floppy Emu Smartport hard disk even when it is Unit 2.
