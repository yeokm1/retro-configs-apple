See https://youtu.be/INOj5k-69js for a video demo of the firmware update process.

SETUP
1. Copy the file femu.bin to the root directory of your SD card
2. Insert the card into your Floppy Emu, and turn on your computer.

FIRMWARE UPDATE 
1. Hold down the SELECT and PREV buttons.
2. Press and release the RESET button.
3. Continue holding SELECT and PREV until the firmware update process begins (about 1 second).
4. Wait 10-15 seconds for the process to complete. Status LED will be flashing.
5. When finished, the LCD will display version information, and the main menu.

Confirm the new firmware version number is displayed on the LCD during Floppy Emu startup.

Note: This is a unified firmware that combines the AVR and CPLD data into a single file. Unlike
earlier firmware versions, there's no need to worry about separate Part 1 and Part 2 files.
